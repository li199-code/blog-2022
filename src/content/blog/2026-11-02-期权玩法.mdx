## 失败经历

从9月份开通etf期权以来，一直做买方，成功率实在低的吓人。

![](https://img.jasonleehere.com/20261102/b1d19e4f73c54d28.png)

9月份做空的理由是美联储加息，结果那几天科创板涨了；10月份做多理由是超跌反弹，且过于信任上证50所谓的稳定，全仓做多，亏惨了。

两次下跌浪中间的小反抽就让看跌爆了；一轮不讲道理的瀑布杀跌过程中强行超跌反弹，也能让看涨爆炸。

期权的玩法，不在买方，不是买彩票这种行为。

## 基于波动率的创业板期权玩法

![](https://img.jasonleehere.com/20261110/2cf353d01087427a.png)

我观察了近三年的创业板期权波动率，把关键节点标注出来：

| 日期 | 类型 | 形成方式及后续走势 |
| --- | --- | --- |
| 2024.2.2 | 波峰 | 跌出来的；之后到2024.9.24震荡（先涨后跌） |
| 2024.9.24 | 波峰 | 涨出来的，短时间快涨贡献了异常值；之后到2025.4.7是震荡 |
| 2025.4.7 | 波峰 | 跌出来的；之后到2025.9.1是大牛市 |
| 2025.9.1 | 波峰 | 涨出来的；之后到2026.4.8是震荡 |
| 2026.4.8 | 波谷 | 此前在历史分位低处呆了超过4个月；之后到6月底走出大牛市 |
| 2026.7.17/7.31 | 波峰 | 跌出来的；之后震荡到9.23 |
| 2026.9.23 | 波谷 | 不算特别低的分位；继续下跌到11.5 |
| 2026.11.5 | 波峰 | 跌出来的；？ |

总结规律：

1. 波峰后做卖方ok，做带来波峰方向相反的卖方，比如涨上来的波峰，你就做看涨的卖方
2. 波峰到波谷的过程中，大概率是震荡，小概率会单边行情
3. 波谷到波峰，可能很快，指数巨幅变动导致在几天的时间冲顶；也可以是慢慢的在周线级别和月线级别的大趋势中爬上去。适合做买方
4. 到达波谷后，可能会磨底，也可能短期内就开始爬升。应该在触底后密切观察，并在趋势形成时，及时切换买方策略
5. 卖方时间段：从波峰向波谷；买方时间段：波谷向波峰
